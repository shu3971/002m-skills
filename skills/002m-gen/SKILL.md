# 002M 主页生图

002M 画境（002m.com）是 AI 图片提示词与视觉灵感库，主打人像写真：266 条真人写真提示词，覆盖旅行、旗袍、复古胶片、夜景、海报、情侣等场景。本技能让用户在对话里直接用它：找提示词，或用一张照片生成写真照。要换装/试衣间请用「002M 试衣间」技能。

## 什么时候用这个技能

用户提到以下任一意图时使用：

- 找写真/人像/换装提示词（“找个……提示词”“想拍……风格”）
- 用照片生成写真照（“用这张照片生成……”“把我 P 成……”）
- 查 002M 生成额度（“还剩几次”“免费额度”）
- 核销 002M 付费码（用户主动给码时）

与写真、提示词、生图无关的请求不要用这个技能。需要给人物换衣服、换装的走「002M 试衣间」。

## 能力一：找提示词

1. 读 `@references/prompts.md`（48 条精选，含中文提示词、英文提示词、案例页链接）。
2. 按用户说的场景/风格/服装/心情匹配最贴切的 1–3 条，返回：标题、中文提示词（给用户看）、案例页链接。
3. 如果精选里没有合适的，告诉用户去 002m.com 搜完整库（266 条），不要现编提示词——002M 的口径是只推网上流行、经过验证的提示词，不原创。
4. 只给提示词、不生成时，不消耗任何额度。

## 能力二：用照片生成写真照

生成走 `scripts/002m-gen.py`（Python 3，只用标准库，不用装任何包）。不要自己拼 HTTP 请求，不要把照片发给别的服务。

### 步骤

1. 先确认用户照片：问用户要一张照片文件路径（JPG/PNG）。没有照片也可以纯文生图，但要先告诉用户：有照片保脸效果更好。
2. 定提示词：优先用能力一找到的提示词（英文提示词发给模型）；用户自己写的提示词也可以直接用。
3. 查额度：跑 `python3 scripts/002m-gen.py status`，看免费剩余（trialLeft）和付费余额（credit）。
4. 生成：跑 `python3 scripts/002m-gen.py gen --photo <照片路径> --prompt "<英文提示词>" --out <保存路径>`。没照片时去掉 `--photo`，纯文生图。默认尺寸 3:4（1152x1536），适合写真。
5. 把生成结果告诉用户：图片已保存到哪个路径。生成成功一次扣一次额度（免费 3 张先扣免费，之后扣付费余额）。

### 额度与付费

- 每台设备免费 3 张（一次性）。免费额度用完后，生成会报 `免费试用 3 张已用完`。
- 额度用完时不要反复重试。告诉用户：去 https://gen.002m.com 支付宝买付费码（9 张 ¥4.9、20 张 ¥9.9、90 张 ¥39.9），买完把付费码发给你核销。
- 用户给码后跑 `python3 scripts/002m-gen.py redeem --code <付费码>`，核销成功会显示新增额度，再重新生成。
- 付费码只用于这一次核销调用，不要存下来、不要写进日志、不要发给别人。核销完就忘掉它。
- 全站每天最多 100 张，万一报 `今日全站额度已满`，让用户明天再来。

### 隐私

- 用户照片只发给 gen.002m.com 用于本次生成，不存原照片；成图在服务器存 30 天。
- 不要把用户照片上传到任何其他地方。

## 能力三：查额度

跑 `python3 scripts/002m-gen.py status`，直接报：免费剩余几张、付费余额几张。不用解释太多。

## 注意事项

- 生成失败不扣额度（服务器只在出图成功后扣）。失败时看脚本报的错：网络问题稍后重试；`上游未出图`稍后重试；额度问题按上面付费流程走。
- 提示词里的 `[HUMAN]`、`[FEATURE]`、`[TEXT]` 这类占位符是变量，生成前要换成具体内容（比如把 `[TEXT]` 换成用户要印的字），不要原样发给模型。
- 涉及真人明星、一眼能认出的公众人物、未成年人时，拒绝生成并说明原因。
- 完整案例库、姿势库、服装库在 002m.com。
