# 002M 试衣间 · AI 换装

002M 试衣间（tryon.002m.com）可以传一张人物全身照，选一件或一套衣服，一键生成 3:4 换装照；也可以先选一个姿势再换装。本技能把试衣间能力接进对话：用户给照片和衣服，直接出换装图。要找提示词/拍写真，用「002M 主页生图」技能。

## 什么时候用这个技能

用户提到以下任一意图时使用：

- 试衣/换装（“用这张照片试穿……”“穿上……效果图”“把我 P 成穿这件衣服”）
- 给人物换一件/一套衣服（上衣+下装）
- 换装同时指定姿势（先选姿势再换装）
- 查试衣间生成额度（“还剩几次”“免费额度”）——与生图站额度共用

与换装/试衣无关的请求不要用这个技能。

## 能力一：换装生成（核心）

生成走 `scripts/002m-tryon.py`（Python 3，需要 Pillow：`pip install Pillow`）。不要自己拼 HTTP 请求，不要把照片发给别的服务。

### 步骤

1. 确认用户照片：问用户要一张人物全身照路径（JPG/PNG，建议全身、站立）。没有照片没法换装。
2. 确认要穿的衣服：用户给服装图路径。可以是一件（单件），也可以是两件（上衣+下装，套装合成一张）。
3. 可选姿势：用户选了姿势就传姿势图路径（姿势线稿可去 tryon.002m.com 姿势库挑，或用户自己给）。不选姿势默认按人物照片原有姿势。
4. 可选场景：用户想换背景/氛围，就描述一句场景（如“明亮的摄影棚，浅灰背景，自然柔光”）。
5. 查额度：跑 `python3 scripts/002m-tryon.py status`，看免费剩余（trialLeft）和付费余额（credit）。
6. 生成：
   - 单件：`python3 scripts/002m-tryon.py gen --photo <人物照> --cloth <服装图> [--pose <姿势图>] [--scene "<场景>"] --out <保存路径>`
   - 套装：`python3 scripts/002m-tryon.py gen --photo <人物照> --cloth <上衣> --cloth <下装> [--pose <姿势图>] [--scene "<场景>"] --out <保存路径>`
   - 只换姿势不换衣：`--photo <人物照> --pose <姿势图> --out <保存路径>`
7. 把结果告诉用户：图已保存到哪个路径。成功一次扣一次额度（免费 3 张先扣免费，之后扣付费余额）。额度与 002M 主页生图共用。

### 换装出图规则

- 一张照片换一件衣服：一次出一张换装照；多件衣服要逐张出，每件各跑一次生成（各扣一次额度），不要一次把多件一起传。
- 套装（2 张：上衣+下装）合成一张完整搭配照。
- 换装会保留人物脸、发型、身材和照片原背景/氛围；选了姿势就按姿势图生成同姿势写实全身照。

## 能力二：查额度

跑 `python3 scripts/002m-tryon.py status`，直接报：免费剩余几张、付费余额几张。额度与生图站共用，不用解释太多。

## 额度与付费

- 每台设备免费 3 张（一次性）。免费额度用完后，生成会报 `免费试用 3 张已用完`。
- 额度用完时不要反复重试。告诉用户：去 https://gen.002m.com 支付宝买付费码（9 张 ¥4.9、20 张 ¥9.9、90 张 ¥39.9），买完把付费码发给你核销。
- 用户给码后跑 `python3 scripts/002m-tryon.py redeem --code <付费码>`，核销成功会显示新增额度，再重新生成。
- 付费码只用于这一次核销调用，不要存下来、不要写进日志、不要发给别人。核销完就忘掉它。
- 全站每天最多 100 张，万一报 `今日全站额度已满`，让用户明天再来。

## 隐私

- 用户照片只在点生成时发给 gen.002m.com 用于本次生成，本技能不存原照片；成图在服务器存 30 天。
- 不要把用户照片上传到任何其他地方。

## 注意事项

- 生成失败不扣额度（服务器只在出图成功后扣）。失败时看脚本报的错：网络问题稍后重试；`上游未出图`稍后重试；`内容被拒（451）`可能是人物照或服装图不通过内容检查，换一件穿着得体的服装或换张人物照再试；额度问题按上面付费流程走。
- 涉及真人明星、一眼能认出的公众人物、未成年人时，拒绝生成并说明原因。
- 服装图只用公开服装库（jsDelivr 转接 GitHub 仓库），图不进本站，仅作生成参考。
